# Google Sheets Cleaning Scripts

This repository contains Google Apps Script code snippets for cleaning and processing data in Google Sheets.

## Clean Truncated Emails 
The spreadsheet serves the purpose of organizing and refining raw data. Specifically, the sheet tab named "Clean Truncated emails" contains emails that have been truncated, such as nashbalraj@g..... The purpose of this Macro is to clean and correct the data, displaying it as nashbalraj@gmail.com. Additionally, the Macro eliminates duplicates and removes any unnecessary white spaces to ensure data accuracy.
